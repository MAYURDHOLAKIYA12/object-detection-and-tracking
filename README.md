### Object Detection and Tracking

*Technologies:* Python, OpenCV, YOLO, Computer Vision

* Developed a real-time object detection and tracking system using computer vision techniques to identify and monitor multiple objects in video streams.
* Implemented the YOLO object detection model with OpenCV for fast and accurate object localization and classification.
* Integrated object tracking to maintain unique identities of detected objects across consecutive video frames.
* Optimized the application for real-time performance, enabling efficient processing of live camera feeds and recorded videos.
* Applied image preprocessing and frame-by-frame analysis to improve detection accuracy under varying conditions.
* Designed a modular and scalable codebase, allowing support for different object detection models and future feature enhancements.
